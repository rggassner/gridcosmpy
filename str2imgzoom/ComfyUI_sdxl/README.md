# str2imgzoom
 
Turn a text (a book, a poem, a script) into an **infinite-zoom image sequence**, one frame per passage, using a local [ComfyUI](https://github.com/comfyanonymous/ComfyUI) instance and an SDXL inpainting workflow.
 
Each frame is generated by shrinking the previous chosen image into the center of a black canvas and letting the model paint everything around it, guided by the next passage of text. Played in reverse, the frames give you a continuous zoom-in; played forward, a zoom-out.
 
You pick the best candidate for every passage in the terminal, so the story and the look stay under your control.
 
## How it works
 
```
0-book.txt ──► 1-textCleaning.sh ──► 2-split.py ──► 2-book.txt (one passage per line)
                                                        │
                                                        ▼
                                          comfyui_infinite_zoom.py
                                                        │
        ┌───────────────────────────────────────────────┤
        │  for each passage:                            │
        │   1. place previous frame (25% size) on black canvas
        │   2. queue the ComfyUI workflow N times (different seeds)
        │   3. you choose the best candidate
        │   4. save it as out/NNNN.png and build the next canvas
        └───────────────────────────────────────────────┘
```
 
Inside ComfyUI the workflow (`infinite_zoom_api_sdxl.json`) does the following:
 
1. Loads the canvas and the mask.
2. Converts the mask's red channel to a mask.
3. Encodes the canvas for inpainting (`VAE Encode (for Inpainting)`).
4. Patches an SDXL checkpoint with the **Fooocus inpaint** patch.
5. Samples, decodes, then **pastes the original center back** with `ImageCompositeMasked`, so the preserved area is pixel-identical and only a thin blend band is repainted.
## Requirements
 
### Hardware
 
- An NVIDIA GPU with **12 GB+ VRAM** recommended (SDXL at 1024×1024). Developed on an RTX 5060 Ti with 16 GB.
- For Blackwell cards (RTX 50 series), use a PyTorch build with **CUDA 12.8 or newer** in ComfyUI's environment.
### Software
 
- Python 3.10+
- A working [ComfyUI](https://github.com/comfyanonymous/ComfyUI) installation, running locally (default `http://127.0.0.1:8188`)
- Python packages for the driver script:
```bash
pip install requests pillow
```
 
### ComfyUI custom nodes
 
Install via **ComfyUI-Manager** (search by name) or `git clone` into `ComfyUI/custom_nodes/`, then restart ComfyUI:
 
| Node pack | Purpose | Repository |
|---|---|---|
| ComfyUI Inpaint Nodes | Provides `INPAINT_LoadFooocusInpaint` and `INPAINT_ApplyFooocusInpaint` | https://github.com/Acly/comfyui-inpaint-nodes |
 
All other nodes used (`CheckpointLoaderSimple`, `LoadImage`, `ImageToMask`, `VAEEncodeForInpaint`, `InvertMask`, `ImageCompositeMasked`, `KSampler`, `VAEDecode`, `SaveImage`, `CLIPTextEncode`) are part of core ComfyUI.
 
### Models
 
| File | Location | Source |
|---|---|---|
| An SDXL checkpoint, e.g. `sd_xl_base_1.0.safetensors` | `ComfyUI/models/checkpoints/` | Any SDXL checkpoint works |
| `fooocus_inpaint_head.pth` | `ComfyUI/models/inpaint/` | `lllyasviel/fooocus_inpaint` on Hugging Face |
| `inpaint_v26.fooocus.patch` | `ComfyUI/models/inpaint/` | `lllyasviel/fooocus_inpaint` on Hugging Face |
 
If your files have different names, edit the `ckpt_name` (node `4`) and the `head` / `patch` fields (node `16`) in `infinite_zoom_api_sdxl.json`.
 
Check each model's license before using the output commercially.
 
## Project layout
 
```
str2imgzoom/
├── 0-book.txt                  # your source text (you provide this)
├── 1-textCleaning.sh           # joins lines, removes hyphenation marks, squeezes spaces
├── 2-split.py                  # wraps the text into ~100-character passages
├── 2-book.txt                  # generated: one passage per line
├── comfyui_infinite_zoom.py    # the driver: queues ComfyUI jobs, asks you to choose
├── infinite_zoom_api_sdxl.json # ComfyUI workflow, API format
├── 0_1024.png                  # black 1024x1024 starting canvas
├── mask_overlap_1024.png       # inpaint mask (224px black square at offset 400)
└── out/
    ├── 0001.png ...            # your selected frame for each passage
    ├── candidates/             # every generated candidate
    ├── canvases/               # the zoom canvas built for each next step
    └── project_state.json      # resume information
```
 
The older Stable Diffusion 2 / diffusers scripts (`3-iterateTxt.sh`, `4-genOptions.py`) are the original pure-Python version and are no longer needed.
 
## Geometry
 
The mask and canvas sizes are chosen so every edge falls on the 8-pixel VAE latent grid:
 
| Item | Size | Position |
|---|---|---|
| Canvas | 1024 × 1024 | n/a |
| Previous frame, shrunk | 256 × 256 | offset 384 |
| Preserved area (black in mask) | 224 × 224 | offset 400 |
 
The 16-pixel ring between the preserved area and the edge of the shrunk frame is repainted by the model. That ring is the blend zone that hides the seam. A smaller black square gives a wider blend; a larger one keeps more of the previous frame but makes the seam more visible.
 
If you change the canvas size, keep `CENTER_SCALE`, the mask offsets and all edges as multiples of 8.
 
## Usage
 
1. Put your text in `0-book.txt`.
2. Prepare the passages:
```bash
   ./1-textCleaning.sh
   python3 2-split.py
```
 
   This creates `2-book.txt` with one passage per line. You can also write the file by hand, which works well for storyboards (see the tips below).
 
3. Start ComfyUI.
4. If ComfyUI is not installed at `/home/rgg/apps/ComfyUI`, tell the script where its input folder is:
```bash
   export COMFY_INPUT_DIR=/path/to/ComfyUI/input
```
 
5. Check the configuration at the top of `comfyui_infinite_zoom.py`:
```python
   INITIAL_IMAGE = PROJECT_DIR / "0_1024.png"
   MASK_IMAGE = PROJECT_DIR / "mask_overlap_1024.png"
   WORKFLOW_FILE = PROJECT_DIR / "infinite_zoom_api_sdxl.json"
 
   CANVAS_WIDTH = 1024
   CANVAS_HEIGHT = 1024
   CENTER_SCALE = 0.25
```
 
6. Run it:
```bash
   python3 comfyui_infinite_zoom.py --count 3 --steps 30 --cfg 6
```
 
   For each passage the script generates `--count` candidates, lists them in `out/candidates/`, and asks you which one to keep. Open them in an image viewer, type the number, and it moves on.
 
### Options
 
| Option | Default | Meaning |
|---|---|---|
| `--url` | `http://127.0.0.1:8188` | ComfyUI address |
| `--count` | 4 | Candidates per passage |
| `--steps` | 30 | Sampler steps |
| `--cfg` | 7.0 (use ~6 for SDXL) | Prompt strength |
| `--denoise` | 1.0 | Keep at 1.0 for the repainted area |
| `--start-at` | 1 | Resume at a given passage |
 
### Resuming
 
Selections are saved to `out/project_state.json` immediately. You can stop with `Ctrl+C` or `q` at any time and run the script again; completed passages are skipped and the next canvas is rebuilt automatically.
 
If you switch resolution or model mid-project, use a new `OUTPUT_DIR` (for example `out_sdxl`) so old frames are not mixed into the new sequence.
 
## Writing good passages
 
- **Write for zoom-out.** Each line should be a wider view that could contain the previous scene at its center.
- **Keep a consistent style.** Add the same style suffix to every line (for example `, digital painting, soft cinematic lighting, highly detailed`).
- **Be visual.** Raw book sentences are often abstract. Rewriting each line as a concrete scene (objects, light, setting) gives much better results. A local LLM (for example through Ollama) is a good tool for this step.
- **Keep it short.** 20 to 30 words is plenty for SDXL.
## Making the animation
 
Each new frame shows the previous one at 25% size, so consecutive frames are related by a **4× zoom**. Animate by scaling frame *N* from 1× to 4× toward the center while cross-fading to frame *N+1*. Reverse the frame order to zoom in instead of out.
 
## Troubleshooting
 
| Problem | Likely cause and fix |
|---|---|
| `Workflow is missing configured node IDs` | The node IDs at the top of the script don't match your workflow. The provided JSON uses `10, 11, 12, 6, 3, 9`. |
| ComfyUI rejects the workflow with a "missing node type" error | ComfyUI Inpaint Nodes isn't installed, or ComfyUI wasn't restarted. |
| Model file errors for the Fooocus head/patch | Files are not in `ComfyUI/models/inpaint/`, or the names differ from node `16`. |
| `no kernel image is available` | PyTorch in ComfyUI's environment is too old for your GPU. For RTX 50 series, install a CUDA 12.8+ build. |
| Visible ring around the center | Make the mask's black square smaller (for example 208px at offset 408) to widen the blend zone. |
| Center loses detail | Make the black square larger (for example 240px at offset 392). |
| Out of memory | Lower the resolution, close other GPU programs, or use fewer candidates per run. |
| Script can't find uploaded images | Set `COMFY_INPUT_DIR`, or switch to ComfyUI's `/upload/image` endpoint. |
